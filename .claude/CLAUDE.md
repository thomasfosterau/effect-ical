# Claude Code

Read README.md, docs/CONTRIBUTING.md and AGENTS.md (imported below). This file covers only Claude Code specifics.

- **Hooks** (`.claude/settings.json`): a PreToolUse hook (`.claude/hooks/fallow-gate.sh`, generated by `fallow hooks install --target agent --agent claude`; regenerate rather than edit it) blocks `git commit` / `git push` when `fallow audit` fails against `FALLOW_AUDIT_BASE` (`origin/trunk`, set in `settings.json`). It reads the coverage map on disk, so run `vp run test:coverage` first. A PostToolUse hook runs `vp fmt --write` on each edited file.
- **Worktrees** go under `.claude/worktrees/`, one per branch; run `vp install` in each.
